Users API

Kelola data pengguna: mengambil daftar, detail, membuat, dan menghapus. Semua endpoint memerlukan header autentikasi.

Base URL https://api.gatrion.com/v2 Operational
GET /users

List Users

Mengembalikan daftar pengguna dengan paginasi. Diurutkan berdasarkan tanggal pembuatan (terbaru dulu).

Query Parameters

limit integer opsional

Jumlah item per halaman. Default 20, maks 100.

cursor string opsional

Kursor paginasi dari respons sebelumnya.

role enum admin | user

Filter berdasarkan peran pengguna.

curl https://api.gatrion.com/v2/users?limit=20 \
  -H "Authorization: Bearer $TOKEN"
const res = await fetch(
  "https://api.gatrion.com/v2/users?limit=20",
  { headers: { Authorization: `Bearer ${token}` } }
);
import requests

r = requests.get(
  "https://api.gatrion.com/v2/users",
  headers={"Authorization": f"Bearer {token}"})

POST /users

Create User

Membuat pengguna baru. Email harus unik.

Body Parameters

name string wajib

Nama lengkap pengguna.

email string wajib

Alamat email valid & unik.

role enum opsional

Default user.

request body 
{
  "name": "Budi Santoso",
  "email": "budi@mail.com",
  "role": "user"
}
201 Created 
{ "id": "usr_a91c", "name": "Budi Santoso" }

404Not FoundResource tidak ditemukan.
