Semua komponen di-inject secara global ke MDX. Gunakan langsung — **jangan menambahkan import ke file konten**.

## Code block

Gunakan fenced code standar. Shiki menangani syntax highlighting dan tema menambahkan label bahasa serta tombol salin.

```ts
const greeting = `Halo, ${user.name}`;
```

Template literal dan `${expression}` aman karena kode adalah Markdown, bukan prop JSX.
