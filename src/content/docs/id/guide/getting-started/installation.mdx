## Prasyarat

- **Node.js 22 atau lebih baru**
- **Git**
- Editor atau agen coding AI apa pun

## Clone dan pasang

```bash
git clone https://github.com/adi-santoso/gatrion-docs.git
cd gatrion-docs
npm install
```

## Jalankan dev server

```bash
npm run dev
```

Buka `http://localhost:4321` di browser Anda. Perubahan konten langsung terlihat.
