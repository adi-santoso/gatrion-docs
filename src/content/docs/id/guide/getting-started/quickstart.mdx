## 1. Konfigurasi situs

Buka `site.config.ts` dan atur URL situs, judul, dan locale Anda.

## 2. Tambahkan proyek

Jalankan generator proyek dan jawab prompt-nya:

```bash
npm run gen:project
```

## 3. Tambahkan halaman

Jalankan generator halaman:

```bash
npm run gen
```

Pilih proyek dan tipe halaman. Skrip menulis file di setiap locale.

## 4. Build dan publikasikan

```bash
npm run build
```

Output statis di `dist/` siap di-deploy ke host mana pun.
