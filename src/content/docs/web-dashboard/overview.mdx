<h2 id="quick-start" class="group scroll-mt-24 text-xl font-bold tracking-tight text-zinc-900 dark:text-white">
  <a href="#quick-start" class="flex items-center gap-2">Quick Start <span class="text-violet-400 opacity-0 transition group-hover:opacity-100">#</span></a>
</h2>

<p class="mt-3 leading-relaxed">Clone repository dan jalankan development server:</p>

<CodeBlock code={`# clone repository
git clone https://github.com/gatrion/web-dashboard.git
cd web-dashboard

# install dependencies
pnpm install

# copy environment file
cp .env.example .env.local`} lang="bash" title="terminal" />

<Callout type="info">
  **Penting:** Pastikan Core API sudah berjalan di <code class="rounded-md bg-violet-500/10 px-1.5 py-0.5 font-mono text-[12px] text-violet-600 dark:text-violet-300">http://localhost:8000</code> sebelum menjalankan dashboard.
</Callout>

<CodeBlock code={`# start development server
pnpm dev`} lang="bash" title="terminal" />

<p class="mt-4 leading-relaxed">Dashboard akan tersedia di <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[13px] text-violet-600 dark:bg-white/[.06] dark:text-violet-300">http://localhost:3000</code></p>
</section>
