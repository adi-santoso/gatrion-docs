## 1. Configure the site

Open `site.config.ts` and set your site URL, title, and locales.

## 2. Add a project

Run the project generator and answer the prompts:

```bash
npm run gen:project
```

## 3. Add a page

Run the page generator:

```bash
npm run gen
```

Pick a project and a page type. The script writes a file in every locale.

## 4. Build and ship

```bash
npm run build
```

The static output in `dist/` is ready to deploy to any host.
