## Prerequisites

- **Node.js 22 or newer**
- **Git**
- Any editor or AI coding agent

## Clone and install

```bash
git clone https://github.com/adi-santoso/gatrion-docs.git
cd gatrion-docs
npm install
```

## Start the dev server

```bash
npm run dev
```

Open `http://localhost:4321` in your browser. Content edits appear immediately.
