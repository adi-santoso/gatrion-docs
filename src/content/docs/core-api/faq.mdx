<div class="mt-4 space-y-4">

    <p class="font-semibold text-zinc-900 dark:text-white">Q: Bagaimana cara menjalankan Core API tanpa Docker?</p>
    <p class="mt-2 text-sm text-zinc-600 dark:text-zinc-400">Install PostgreSQL dan Redis secara manual, set <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">DATABASE_URL</code> dan <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">REDIS_URL</code> di <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">.env</code>, lalu jalankan <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">npm run dev</code>.</p>
  </div>

  <div class="rounded-xl border border-zinc-200 bg-white/60 p-4 dark:border-white/[.07] dark:bg-white/[.02]">
    <p class="font-semibold text-zinc-900 dark:text-white">Q: Node version apa yang dibutuhkan?</p>
    <p class="mt-2 text-sm text-zinc-600 dark:text-zinc-400">Node.js ≥ 18 (LTS). Gunakan <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">nvm use</code> — versi sudah didefinisikan di <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">.nvmrc</code>.</p>
  </div>

  <div class="rounded-xl border border-zinc-200 bg-white/60 p-4 dark:border-white/[.07] dark:bg-white/[.02]">
    <p class="font-semibold text-zinc-900 dark:text-white">Q: Error "Cannot connect to database" saat startup?</p>
    <p class="mt-2 text-sm text-zinc-600 dark:text-zinc-400">Pastikan PostgreSQL berjalan dan <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">DATABASE_URL</code> benar. Cek dengan: <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">docker compose ps</code> atau <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">pg_isready</code>.</p>
  </div>
</div>

<section class="animate-fade-up [animation-delay:.15s]">
<h2 id="authentication" class="group scroll-mt-24 text-xl font-bold tracking-tight text-zinc-900 dark:text-white">
  <a href="#authentication" class="flex items-center gap-2">Authentication <span class="text-violet-400 opacity-0 transition group-hover:opacity-100">#</span></a>
</h2>

<div class="mt-4 space-y-4">
  <div class="rounded-xl border border-zinc-200 bg-white/60 p-4 dark:border-white/[.07] dark:bg-white/[.02]">
    <p class="font-semibold text-zinc-900 dark:text-white">Q: Berapa lama access token valid?</p>
    <p class="mt-2 text-sm text-zinc-600 dark:text-zinc-400">Access token valid selama <strong>1 jam</strong> (configurable via <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">JWT_EXPIRES_IN</code>). Refresh token valid <strong>7 hari</strong>.</p>
  </div>

  <div class="rounded-xl border border-zinc-200 bg-white/60 p-4 dark:border-white/[.07] dark:bg-white/[.02]">
    <p class="font-semibold text-zinc-900 dark:text-white">Q: Bagaimana cara invalidate token sebelum expiry?</p>
    <p class="mt-2 text-sm text-zinc-600 dark:text-zinc-400">Tambahkan token ke Redis blacklist dengan TTL = sisa waktu expiry. Implementasi ada di <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">JwtBlacklistGuard</code>.</p>
  </div>
</div>
</section>

</h2>

<div class="mt-4 space-y-4">
  <div class="rounded-xl border border-zinc-200 bg-white/60 p-4 dark:border-white/[.07] dark:bg-white/[.02]">
    <p class="font-semibold text-zinc-900 dark:text-white">Q: Bagaimana cara scale Core API?</p>
    <p class="mt-2 text-sm text-zinc-600 dark:text-zinc-400">Horizontal scaling dengan Docker Swarm atau Kubernetes. Pastikan Redis shared instance untuk session dan rate limiting. Gunakan load balancer (Nginx/Traefik) di depan.</p>
  </div>

  <div class="rounded-xl border border-zinc-200 bg-white/60 p-4 dark:border-white/[.07] dark:bg-white/[.02]">
    <p class="font-semibold text-zinc-900 dark:text-white">Q: Berapa minimal resource yang dibutuhkan?</p>
    <p class="mt-2 text-sm text-zinc-600 dark:text-zinc-400">Production minimal: <strong>1 CPU, 1GB RAM</strong>. Recommended: <strong>2 CPU, 2GB RAM</strong> dengan connection pool 10-20.</p>
  </div>
</div>
</section>

(2) N+1 query — gunakan <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[12px] dark:bg-white/[.06]">include</code> di Prisma. (3) Redis tidak terhubung — cache tidak bekerja.</p>
