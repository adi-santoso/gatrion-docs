  <a href="#installation" class="flex items-center gap-2">Instalasi <span class="text-violet-400 opacity-0 transition group-hover:opacity-100">#</span></a>
</h2>

<p class="mt-3 leading-relaxed">Kloning repositori dan instal seluruh dependensi:</p>

<CodeBlock code={`# kloning & masuk direktori
git clone https://github.com/gatrion/core-api.git
cd core-api

# instal dependensi & salin env
npm install
cp .env.example .env`} lang="bash" title="terminal" />

<Callout type="info">
  **Tips:** Gunakan <code class="rounded-md bg-violet-500/10 px-1.5 py-0.5 font-mono text-[12px] text-violet-600 dark:text-violet-300">nvm use</code> — file <code class="rounded-md bg-violet-500/10 px-1.5 py-0.5 font-mono text-[12px] text-violet-600 dark:text-violet-300">.nvmrc</code> sudah tersedia di root project.
</Callout>
</section>

<section class="animate-fade-up [animation-delay:.2s]">
<h2 id="running-the-server" class="group scroll-mt-24 text-xl font-bold tracking-tight text-zinc-900 dark:text-white">
  <a href="#running-the-server" class="flex items-center gap-2">Menjalankan Server <span class="text-violet-400 opacity-0 transition group-hover:opacity-100">#</span></a>

<p class="mt-3 leading-relaxed">Jalankan database via Docker, lalu start development server:</p>

<CodeBlock code={`docker compose up -d
npm run db:migrate
npm run dev`} lang="bash" title="terminal" />

<p class="mt-4 leading-relaxed">Jika berhasil, API tersedia di <code class="rounded-md bg-zinc-100 px-1.5 py-0.5 font-mono text-[13px] text-violet-600 dark:bg-white/[.06] dark:text-violet-300">http://localhost:8000</code> dengan output:</p>
