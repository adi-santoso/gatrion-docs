Getting Started

Core API adalah backbone dari seluruh layanan Gatrion. Panduan ini membawamu dari nol sampai server berjalan di lokal — kurang dari 5 menit.

Prasyarat #

Pastikan tools berikut sudah terpasang sebelum lanjut:

node ≥ 18

Runtime utama

postgres ≥ 15

Database

redis ≥ 7

Cache & queue

Instalasi #

Kloning repositori dan instal seluruh dependensi:

terminal 
# kloning & masuk direktori
git clone https://github.com/gatrion/core-api.git
cd core-api

# instal dependensi & salin env
npm install
cp .env.example .env

Tips

Gunakan nvm use — file .nvmrc sudah tersedia di root project.

Menjalankan Server #

Jalankan database via Docker, lalu start development server:

terminal 
docker compose up -d
npm run db:migrate
npm run dev

Jika berhasil, API tersedia di http://localhost:8000 dengan output:

✓ Database connected (postgres@localhost:5432)
✓ Redis connected
✓ Server listening on http://localhost:8000

Struktur Direktori #

Gambaran singkat organisasi kode:

core-api/
├── src/
│   ├── modules/     # fitur per domain (users, orders, ...)
│   ├── common/      # guard, interceptor, util bersama
│   ├── config/      # konfigurasi env & database
│   └── main.ts
├── prisma/          # schema & migrasi
├── test/
└── docker-compose.yml
